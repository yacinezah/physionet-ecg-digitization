# Project summary

This repository contains a Kaggle ECG image digitization project.

Pipeline:

1. Stage 0 image normalization.
2. Stage 1 grid rectification.
3. Stage 2 waveform extraction.

Main additions:

- Sparse pseudo-mask generation.
- Modified Stage 2 lead model.
- Cross-lead attention experiment.
- Ablation analysis.

Best reported result: 23.27649 private / 23.37199 public.
