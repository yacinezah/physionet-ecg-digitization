# Model weights

Large model weights and Kaggle datasets are not tracked in this repository.

The notebooks expect external Kaggle inputs for:

- Stage 0 / Stage 1 baseline checkpoints.
- Stage 2 pretrained shared-conv2d checkpoint.
- Optional cross-attention fine-tuning checkpoints.

The final fine-tuned attention state dict generated by the training notebook was named `cross_attn_b6_final.pth` in the Kaggle working directory.
