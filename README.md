# PhysioNet ECG Image Digitization

Portfolio project for the Kaggle / PhysioNet ECG Image Digitization challenge: reconstruct 12-lead ECG time-series signals from scanned or photographed ECG paper images.

This repository documents a complete computer-vision and signal-processing workflow: geometric normalization, ECG grid rectification, trace extraction, sparse pseudo-mask generation, cross-lead attention fine-tuning, and final inference.

## Problem

**Input:** an ECG image.  
**Output:** numerical 12-lead ECG waveforms.  
**Metric:** signal-to-noise ratio (SNR) after competition alignment.

The task is not only segmentation. Small geometric errors in grid rectification produce amplitude and timing errors in the recovered signal, so the pipeline combines computer vision, geometric calibration, segmentation, signal reconstruction, and post-processing.

## Pipeline

```text
Raw ECG image
  -> Stage 0: document normalization and homography
  -> Stage 1: ECG grid detection and rectification
  -> Stage 2: trace segmentation from rectified lead crops
  -> Pixel-to-signal decoding
  -> Kaggle submission.csv
```

## Why the attention model did not win

The cross-lead attention branch was technically implemented and trained successfully, but it did not outperform the simpler convolutional Stage 2 variants in the final leaderboard score.

The main reason is not that attention is a bad idea for ECG. ECG leads are correlated, so cross-lead information sharing is conceptually justified. The limitation was practical optimization under Kaggle constraints:

- The attention model was fine-tuned for only 4 total epochs.
- Training was limited to one epoch per Kaggle GPU session because of runtime quotas.
- Fusion had to be restricted to deep encoder levels `[3, 4]`; lower-resolution encoder fusion was stable, but earlier layers caused memory pressure.
- A full encoder unfreeze was not feasible under the available free GPU/VRAM budget.
- The model learned from pseudo-masks generated by an existing model, not from perfect manual masks.

This is why the final selected solution remains the simpler no-attention variant. The attention experiment is kept in the repository as a meaningful research branch and a negative result: a more expressive model is not automatically better when pseudo-label quality, memory, training time, and end-to-end integration stability are limiting factors.

## How to run

These notebooks are designed for Kaggle, not for direct local execution. They require:

1. the official competition dataset,
2. public baseline checkpoints,
3. the custom `src/stage2_lead_model.py`, copied or packaged as a Kaggle dataset,
4. GPU acceleration.

Typical order:

1. Run `notebooks/01_generate_pseudo_masks.ipynb`.
2. Run `notebooks/02_train_cross_attention.ipynb`.
3. Run `notebooks/03_inference_submission.ipynb`.
